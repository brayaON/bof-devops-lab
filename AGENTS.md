# Contexto del laboratorio
Aplicación educativa en Go, biblioteca estándar, seis tickets ficticios y una interfaz HTML.
El participante aprende DevOps; explica el motivo de cada cambio con lenguaje sencillo.
- Lee la petición y propone un plan breve antes de editar.
- No implementes funciones de futuras sesiones.
- Conserva las rutas y el comportamiento existente salvo lo requerido por el ejercicio.
- No agregues dependencias sin justificarlo y acordarlo.
- No ejecutes comandos Git que descarten cambios ni publiques cambios sin petición.
- No uses credenciales ni datos empresariales.
- Añade pruebas de los nuevos comportamientos y ejecuta go fmt, go test y go vet.
- Si no puedes ejecutar algo, decláralo; no afirmes que pasó.
- Explica los archivos modificados y las comprobaciones realizadas.
